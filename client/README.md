# 🍳 AI-Powered Recipe Generator

An AI-powered recipe generation web application built using the **MERN Stack** and **Google Gemini API**.

The application allows users to enter available ingredients, select their preferred cuisine, dietary preference, and meal type. The system uses Google Gemini AI to generate a complete recipe with ingredients, cooking instructions, preparation time, estimated nutritional information, serving size, and cooking tips.

Users can securely register and log in, save their generated recipes, and manage them from a personal recipe dashboard.

---

## 📌 Project Overview

Finding suitable recipes based on available ingredients and dietary requirements can be difficult.

This project provides an AI-powered solution where users can enter their requirements and receive a personalized recipe generated by Google Gemini.

The application also provides a personal recipe management system where authenticated users can save, search, edit, categorize, and delete their recipes.

# 🔐 Authentication and Authorization

The application uses **JWT (JSON Web Token)** authentication.

### Registration

The user's account information is stored securely in MongoDB.

Passwords are hashed before being stored.

### Login

After successful authentication, the server generates a JWT token.

The frontend uses the token when making protected API requests.

### Authorization

Protected recipe operations require a valid JWT.

This ensures that users can manage only their own saved recipes.

```text
User
 ↓
Login
 ↓
JWT Token
 ↓
Protected API Request
 ↓
Authentication Middleware
 ↓
Authorized Recipe Operation
```

# 🌐 RESTful API

The backend provides RESTful APIs for authentication and recipe management.

## Authentication APIs

### Register

```http
POST /api/auth/register
```

### Login

```http
POST /api/auth/login
```

---

## Recipe APIs

### Generate Recipe

```http
POST /api/recipes
```

### Get User Recipes

```http
GET /api/recipes
```

### Update Recipe

```http
PUT /api/recipes/:id
```

### Delete Recipe

```http
DELETE /api/recipes/:id
```

All protected recipe operations require authentication.

# 🔑 Environment Variables

Create a `.env` file inside the `server` directory.

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
```

For the React frontend:

```env
VITE_API_URL=http://localhost:5000
```

### ⚠️ Security

Never upload your `.env` file or API keys to GitHub.

Add the following to `.gitignore`:

```gitignore
.env
node_modules/
dist/
```
